# Lista 01 - UDWMJ

Projeto da **Lista de Exercícios I** da disciplina Usabilidade, Desenvolvimento Web, Mobile e Jogos.

## Funcionalidade do código

O projeto implementa um **verificador de número par ou ímpar**.

1. O usuário digita um número inteiro.
2. O JavaScript lê o valor informado.
3. O operador de resto (`%`) verifica a divisão por 2.
4. Se o resto for `0`, o número é par.
5. Caso contrário, o número é ímpar.
6. O resultado é exibido na própria página.
